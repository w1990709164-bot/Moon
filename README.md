# 小手机

直接上传本文件夹到 GitHub 仓库，Cloudflare Pages 静态部署即可。

## 页面结构

- `index.html`：小手机主页面，已在每日盲盒右侧新增"游戏"入口，并新增游戏中心页面。
- `games/truthdare.html`：真心话大冒险游戏文件。
- `task.html`：**催猫 · 任务助手**（对话式任务管理工具，详见下方）

## 催猫 · 任务助手 (`task.html`)

一个基于对话界面的任务管理工具，在微信内置浏览器中直接打开使用。

### 核心功能

| 功能 | 说明 |
|------|------|
| **对话式录入** | 直接用自然语言说任务，自动解析时间、优先级，无需手动建清单 |
| **追杀式提醒** | 到点未完成会在页面内反复催你（每隔 N 分钟升级一次措辞），不止响一下 |
| **任务拆解** | 点击任务 → "猫猫帮我拆解"，自动拆成 4-6 个小步骤 |
| **可视化看板** | 三列看板（待办 / 进行中 / 已完成），进度一目了然 |
| **周历视图** | 7 天日历展示截止任务，可前后翻周 |
| **情绪陪伴** | 完成任务有猫猫庆祝，拖延严重会被追着催，支持「鼓励我」指令 |

### 快速使用

1. 部署到 Cloudflare Pages 后，访问 `/task.html`
2. 直接在对话框输入任务，例如：
   - `"明天下午3点开会，后天交报告"`
   - `"这周五前完成PPT，不急"`
   - `"帮我拆解：写年终总结"`
3. 点击右上角 ⚙️ 可配置 Claude API Key（启用后 AI 解析更准）和提醒间隔

### AI 功能（可选）

填入 Claude API Key（`sk-ant-...`）后可启用：
- 更精准的自然语言任务解析
- 个性化任务拆解
- 定制化鼓励话语

无 API Key 时，使用内置正则解析器（支持"明天/后天/周五/X月X日/X点"等常见表达）。

### 提醒机制说明

由于静态部署无后端，提醒依赖**浏览器保持页面打开**。
- 在微信中打开页面后，保持页面不关闭，提醒会通过页面内弹窗 + 对话气泡推送
- 如需真正的微信推送通知（页面关闭后也能收到），需接入微信公众号后端 + 模板消息 API

### 数据存储

所有任务数据存储在浏览器 `localStorage`，清除浏览器数据会丢失任务。
